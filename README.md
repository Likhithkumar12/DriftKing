# Drift Boss Clone

A simple Unity recreation of the popular **Drift Boss** game, where players control a car on an endless twisting track using a single input. The objective is to stay on the road for as long as possible and achieve the highest score.

## Features

- Endless procedurally generated track
- One-touch / one-button controls
- Increasing difficulty over time
- Score tracking
- Smooth drifting movement
- Game Over and Restart system

## Controls

- **Space / Left Mouse Button**
  - Hold to drift
  - Release to straighten the car

## Built With

- Unity
- C#

## How to Play

1. Open the project in Unity.
2. Press **Play**.
3. Stay on the track as long as possible.
4. Beat your highest score!
